# Bismillah Burger House — sample website

A responsive single-page restaurant website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the project folder.
2. Open it in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension.

No build tools or package installation are required.

## Before publishing
- In `script.js`, replace `91XXXXXXXXXX` in `WHATSAPP_NUMBER` with the restaurant's WhatsApp number (country code + number, digits only).
- Check every menu item, price, food description and image against the real menu.
- Confirm the address, opening hours and Google Maps destination.
- Replace the sample customer testimonials with genuine reviews or remove that section.
- The food image files in `images/` are locally bundled crops from a generated website concept mockup. Replace them with the restaurant's own product photography for the final public site.

## Features
- Responsive mobile navigation
- Menu category filters
- Add-to-cart, quantity controls, remove item and subtotal calculation
- WhatsApp order message generation (requires a real number)
- Local image assets and SVG logo

This is a frontend demo. It does not process payments, save orders to a server, or provide an admin dashboard.
